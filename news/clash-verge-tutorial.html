新手教程：Clash Verge Rev 订阅导入与常用分流规则设置

📅 发布日期: 2026-07-28 👤 作者: JcTuijian 教程小组 👁 阅读量: 820 次

Clash Verge Rev 凭借优雅的图形界面以及对新一代 Clash Meta (Mihomo) 内核的完美兼容，已逐步成为 Windows 和 macOS 平台上最主流的科学上网代理客户端。为了帮助零基础的机场新手快速上手，本篇将为您详细梳理软件的安装、订阅配置与常见设置要点。

一、 下载与首次打开

首先，您需要访问我们的 翻墙客户端下载页 获取 Clash Verge Rev 官方安装包或本地纯净分流。安装完成后，首次打开软件可能会提示系统管理员权限弹窗，请选择【允许】以保证虚拟 TUN 网卡驱动可以正确载入。

二、 导入您的机场订阅链接

准备好您已购买的科学上网机场“Clash订阅链接”，随后按以下步骤操作：

  1. 在客户端左侧菜单栏中点击 Profiles (配置)。
  2. 在顶部输入框中粘贴您的机场订阅链接。
  3. 点击输入框右侧的 Import (导入) 按钮。
  4. 等待几秒钟下载完毕后，列表中会多出一个卡片，鼠标左键点击它 使其高亮（表示选中激活此配置）。

若遇到导入失败，通常是订阅地址被本地宽带屏蔽（直连 Github 失败），可在官网临时开启代理，或联系机场主获取代理后的备份链接。

三、 选择节点与启用系统代理

订阅激活后，接下来进行连接设置：

  • 点击左侧菜单的 Proxies (代理) 选项。
  • 在策略组中，选择您中意的地区（如：香港、新加坡、美国、日本等），点击展开并选中一个活跃的节点。
  • 点击左侧菜单的 Settings (设置)，在系统设置模块中，勾选并打开 System Proxy (系统代理) 选项开关。

此时，您即可在浏览器中输入 `google.com` 尝试畅快访问，默认的“Rule (规则) 模式”会自动确保国内网站直连、海外站点自动走代理分流。
