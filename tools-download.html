❓ 科学上网客户端常见问题解答 (FAQ)

1. Windows 翻墙工具推荐选择哪个？
Windows 用户通常优先建议使用 Clash Verge Rev 或 v2rayN。
* Clash Verge Rev：拥有更加现代化美观的图形操作界面，支持中文，非常适合追求美观与跨平台统一体验的用户。
* v2rayN：是 Windows 上的老牌多协议代理客户端，支持最底层的核心组件高度调优，适合对规则、协议有高度自定义要求的极客玩家。
2. iPhone (iOS) 用户推荐用什么翻墙工具？
iPhone 常见首选是 Shadowrocket (小火箭) 和 Stash。
* Shadowrocket：操作极其简单，通过扫码即可自动完成订阅导入，是大多数机场新手的首选。
* Stash：是 iOS 平台非常知名的 Clash 原生协议管理客户端，策略组与分流能力更加细致。这两款软件都属于付费应用，需要配合外区 Apple ID 购买。
3. Android (安卓) 翻墙推荐用 v2rayNG 还是 Karing？
* v2rayNG：非常轻量且省电，只保留核心的节点导入、一键测速及连通开关，适合只想要节点代理直连的普通用户。
* Karing：界面更为现代化美观，交互逻辑更友好。您可根据自身偏好选择，建议优先参考您购买的机场后台提供的推荐与专属配置包。
4. Clash Verge Rev 和 v2rayN 有什么本质区别？
* Clash Verge Rev：主要基于 Clash / Mihomo 开源内核，核心逻辑围绕“策略组与分流机制”，适合实现国内外流量自动路由分流。
* v2rayN：作为经典的 Windows 外壳程序，支持导入 Xray/v2fly/sing-box 等多种协议内核，更偏好原生的配置调优与协议多合一兼容。
5. Clash Verge Rev 怎么快速导入机场订阅？
您只需要在机场后台复制 Clash 订阅链接（或点击“一键导入 Clash”），随后在 Clash Verge Rev 的 Profiles (配置) 选项卡中，将链接粘贴至输入框，点击 Import (导入) 并选中激活该配置即可。
6. v2rayN 怎么导入机场订阅链接并使用？
在 v2rayN 顶部栏选择 订阅分组 -> 订阅分组设置，点击 添加，输入别名并在“可选地址(url)”粘贴机场订阅，保存后点击顶部栏 更新订阅 即可载入所有节点。最后在底部系统状态栏将“系统代理”模式设为【自动配置系统代理】。
7. 为什么我下载了客户端后依然打不开外网？
科学上网客户端只是连接和路由工具，不自带节点资源。您必须购买一个可用的机场服务，获取其“订阅链接”并导入客户端，然后开启代理开关（系统代理或 Tun 虚拟网卡模式），才能够正常访问外网。
8. 机场提供的订阅链接是什么意思？
机场订阅链接是服务商提供的一串私密 API 配置地址，其内部包含了所有可用节点的服务器地址、加密密钥、端口、混淆规则以及剩余流量/过期时间等元数据。客户端通过解析该地址才能拉取并自动更新节点列表。
9. 官方 Github 下载和本地下载有什么不同？
* Github 官方下载：会跳转至开发者的官方项目源，确保您可以获取到最新最纯净的版本。
* 本地下载：为本站提供的本地分流备用包，通常适合在 GFW 封锁严重、用户直连 Github 官方页面速度缓慢甚至完全打不开时使用，安全度与官方包一致。
10. iOS 的 Shadowrocket 为什么在国内 App Store 找不到？
由于中国区 App Store 的监管政策，所有代理类、VPN 类的应用程序均无法在中国大陆区上架及购买。用户必须注册或租赁一个外区（如美国、香港、日本等）的 Apple ID，登录外区 App Store 才能搜索并下载到 Shadowrocket 或 Stash。
